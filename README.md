# Activity 1: Multiple Linear Regression

## Project Description
This project uses Multiple Linear Regression to predict house prices using multiple numerical input features from the California Housing dataset.

## Dataset Used
California_Housing_Sample.csv

## Dataset Source
California Housing Prices Dataset – Kaggle

https://www.kaggle.com/datasets/camnugent/california-housing-prices

## Features (Input Variables)
- MedInc
- HouseAge
- AveRooms
- AveBedrms
- Population
- AveOccup
- Latitude
- Longitude

## Target Variable
MedHouseVal (Median House Value)

## Algorithm Used
Multiple Linear Regression

## Data Preprocessing
- Loading the CSV dataset
- Checking missing values
- Handling missing values
- Exploratory Data Analysis (EDA)
- Correlation heatmap
- Selecting input and target features

## Model Evaluation
- R-squared
- Adjusted R-squared
- RMSE

## Train-Test Split
80% Training Data and 20% Testing Data
